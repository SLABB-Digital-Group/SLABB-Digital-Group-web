# SLABB Digital Group Website

A modern, responsive one-page website for SLABB Digital Group.

## Files
- `index.html` — complete website
- `assets/slabb-logo.png` — supplied SLABB logo

## Notes
The website is built as a static site and can be uploaded to GitHub Pages, Netlify, Vercel, or standard web hosting.

The contact form opens the visitor's email client and prepares an enquiry to:
slabbdigitalgroup@gmail.com

The social buttons are placeholders because the company profile only supplied the social handle `@SLABBDigitalGroup`, not individual profile URLs.
